# Paranoid Reverb — Official Website

Final optimized static build for **paranoidreverb.com**. Ready for GitHub + Vercel.

## Frequent updates
Edit `assets/js/site-data.js` for live dates, streaming links, Bandcamp URLs, social links and contact email.

### Red River Black Roots
When available, paste the official URLs into:
- `bandcampRedRiver` and the album `listen` Bandcamp entry
- `spotifyRedRiverBlackRoots` / the album `listen` Spotify entry
- any currently blank track URL in the Red River Black Roots tracklist

Blank track URLs intentionally render as **SOON** rather than sending visitors to a search page.

## Performance
Large artwork and gallery assets are optimized as WebP. The Vimeo hero loads progressively and falls back to the release artwork for reduced-motion users.

## SEO
Canonical URL, Open Graph, Twitter metadata, MusicGroup structured data, sitemap and robots.txt use `https://paranoidreverb.com/`.
